## ✍️ Answer Writing Guide

### 2 Marks Answer Formula
```
Definition (1 line) + Key Point / Example (1-2 lines)
= Total: 3-5 lines max
```

### 7 Marks Answer Formula
```
1. Introduction / Definition     → 3-4 lines
2. Main Explanation              → 3-4 points with subheadings
3. Diagram / Table / Example     → ZAROOR banana hai
4. Working / Process Steps       → Numbered steps
5. Conclusion / Summary          → 2-3 lines
= Total: 300-400 words
```

> 💡 **Examiner Ki Nazar Se:** Diagram + Subheadings + Keywords = Full Marks
